## ⬆️ Updating

Go-to-Bed updates itself to this version at its next start (or within a day). The download can take a minute or two – just leave Go-to-Bed running; it restarts by itself.

> **Update to 3.1.1 seemed stuck?** Close any open Go-to-Bed message boxes and the settings window. If Go-to-Bed is then no longer in the tray, start it from the Start menu. 3.1.0 waits for open message boxes before it restarts – fixed from this version on.

## 🐛 Fixed

- The self-update could get stuck when a Go-to-Bed message box was open while the update finished. The old version now exits right away and the new one waits for it.

## ✨ Improved

- Notification *"Updating Go-to-Bed"* when an update starts; *Check for Updates* during an update says which version is being installed.
- No update restart while the settings window is open.
