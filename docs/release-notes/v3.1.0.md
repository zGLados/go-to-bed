## ⬆️ Upgrading from 3.0.0

3.0.0 cannot update itself: **download `GotoBed.exe` below and double-click it once** – your running 3.0.0 is replaced automatically, settings and statistics are kept. From now on Go-to-Bed updates itself.

Step-by-step guide and what to do if something looks different: **[Upgrading from 3.0.0 to 3.1](https://github.com/zGLados/go-to-bed/blob/main/docs/upgrade-from-3.0.md)**

> SmartScreen warning? Click *More info → Run anyway* (the exe is not code-signed).

## ✨ New

- **Automatic updates** – checks at every start and daily, installs new versions by itself (or asks you, if you turn that off). **Check for Updates** button in the settings and in the tray.
- **Installs itself** for your Windows user (no admin rights): Start menu entry, *Apps & features* entry, clean uninstall.
- **One-step upgrade** from older versions, including 3.0.0.
- Screenshots in the README.
