## ⬆️ Updating

Go-to-Bed 3.1.0 updates itself to this version at its next start (or within a day). Still on 3.0.0? Download `GotoBed.exe` below and double-click it once – see [Upgrading from 3.0.0](https://github.com/zGLados/go-to-bed/blob/main/docs/upgrade-from-3.0.md).

## ✨ New

- **Okay, I'm going!** now says *Good night! 🌙 Sleep well.* and closes the reminder by itself after 3 seconds.
- Default bedtime is **21:40** for new installations. A bedtime you already saved stays as it is.

Full list: [CHANGELOG](https://github.com/zGLados/go-to-bed/blob/main/CHANGELOG.md)
